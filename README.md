# Getly demo videos

Short screen recordings (11-21 seconds, H.264 MP4) used as the **video preview** on the
product pages of the Getly store **OllamaExperts**
(https://www.getly.store/store/ollamaexperts).

This repository holds only the rendered demo videos - no product source code.

Direct links (used in the Getly product editor -> Media step -> video links):

- `freelancer-billing-demo.mp4`
- `small-business-paperwork-demo.mp4`
- `irregular-income-budget-demo.mp4`
- `rental-property-manager-demo.mp4`
- `ai-prompt-library-demo.mp4`
- `task-list-demo.mp4`

Each clip shows the real app being used with sample data (tasks, invoices, receipts,
budget, tenancies and prompt library), including the settings panel with the
17-language switcher. Recorded with Chrome at 1280x720.
